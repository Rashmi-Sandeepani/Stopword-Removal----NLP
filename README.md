# Stopword-Removal----NLP

### What are stop words?

In below sentence, words like the, and, is, was, it, in are like glue. They hold the sentence together, but they don't tell the topic. These glue words are called stop words (or function words). **Stop-word removal** means throwing away the glue words so the important words (keywords) can be seen.

eg: The bridge was built over the river and it is the longest bridge in the town.

But in some sentences if we remove words like not and no, the meaning flipped completely. Like those situations we should keep those words.

eg: I am not happy with the road because it is not safe.
